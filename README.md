# hrclabsrag — RAG Generator

Upload PDF or TXT documents at runtime and ask questions about them. Answers are generated by Claude from the uploaded documents only, with citations to the source file and page. Each session has its own document set and chat, so the app works with any set of documents without code changes.

See [plan.md](plan.md) for the scope, constraints and design.

## Prerequisites

- **Python 3.9 or newer**. Check with `python3 --version`.
- **An Anthropic API key** from [console.anthropic.com](https://console.anthropic.com/). The account needs available credits, because a key on an account with no credits is rejected with "credit balance is too low".
- About **1 GB of disk space** for dependencies (PyTorch is pulled in by `sentence-transformers`) plus about 130 MB for the embedding model, which is downloaded on first run.

## Setup

```bash
# 1. Clone and enter the repository
git clone <repo-url> hrclabsrag
cd hrclabsrag

# 2. Create and activate a virtual environment
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate

# 3. Install dependencies
pip install --upgrade pip
pip install -r requirements.txt

# 4. Create your config file and add your API key
cp .env.example .env
```

Open `.env` and set your key:

```dotenv
ANTHROPIC_API_KEY=sk-ant-...
```

`.env` is gitignored, so your key is never committed. You can instead export `ANTHROPIC_API_KEY` in your shell; environment variables override `.env`.

## Run

```bash
uvicorn app.main:create_app --factory --reload
```

- Web UI: <http://localhost:8000>
- Interactive API docs: <http://localhost:8000/docs>
- Health check: <http://localhost:8000/api/health>. `"llm_configured": true` confirms the API key was picked up.

On the first start, the embedding model (`BAAI/bge-small-en-v1.5`) downloads from Hugging Face in the background. Later starts load it from the local cache.

App data (session registry and vector index) is stored in `./data/`. Delete that folder to reset everything.

## Using the API

Every document set belongs to a session. Create a session, upload files, then ask questions:

```bash
# Create a session
SID=$(curl -s -X POST localhost:8000/api/sessions | python3 -c "import sys,json; print(json.load(sys.stdin)['session_id'])")

# Upload one or more PDF/TXT files
curl -F "files=@handbook.pdf" -F "files=@faq.txt" localhost:8000/api/sessions/$SID/documents

# List documents in the session
curl localhost:8000/api/sessions/$SID/documents

# Ask a question (answer streams back as Server-Sent Events)
curl -N -X POST localhost:8000/api/sessions/$SID/query \
  -H 'content-type: application/json' \
  -d '{"question": "How many days of annual leave do employees get?"}'

# Delete the session and its documents
curl -X DELETE localhost:8000/api/sessions/$SID
```

The query stream emits these events:

| Event | Data |
|---|---|
| `sources` | Numbered retrieved passages: `id`, `filename`, `page`, `score`, `snippet` |
| `delta` | A piece of answer text (repeated) |
| `done` | `stop_reason`, `cited` (source ids used in the answer), token `usage` |
| `error` | A user-safe `message` (sent instead of `done`) |

For follow-up questions, send earlier turns as `"history": [{"role": "user", "content": "..."}, {"role": "assistant", "content": "..."}]`.

## Configuration

All settings are read from `.env` or the environment. Defaults are in [.env.example](.env.example).

| Variable | Default | Purpose |
|---|---|---|
| `ANTHROPIC_API_KEY` | (none) | Required for answering questions |
| `LLM_MODEL` | `claude-sonnet-5` | Any Claude model ID, e.g. `claude-haiku-4-5` for faster, cheaper answers |
| `LLM_EFFORT` | `medium` | `low` / `medium` / `high` / `xhigh` / `max`. Higher is more thorough but slower |
| `LLM_MAX_TOKENS` | `16000` | Output cap per answer, including thinking |
| `EMBEDDING_MODEL` | `BAAI/bge-small-en-v1.5` | Local sentence-transformers model |
| `DATA_DIR` | `./data` | Where sessions and vectors are stored |
| `MAX_FILE_SIZE_MB` | `10` | Per-file size limit |
| `MAX_PDF_PAGES` | `200` | Per-PDF page limit |
| `MAX_FILES_PER_UPLOAD` | `5` | Files per upload request |
| `MAX_DOCS_PER_SESSION` | `20` | Documents per session |
| `SESSION_TTL_HOURS` | `24` | Idle sessions are deleted after this long |
| `MAX_HISTORY_TURNS` | `6` | Previous Q&A pairs sent to the model |
| `MAX_QUESTION_CHARS` | `2000` | Question length limit |
| `CHUNK_SIZE` / `CHUNK_OVERLAP` | `800` / `150` | Chunking, in characters |
| `TOP_K` | `5` | Passages retrieved per question |

Changing `EMBEDDING_MODEL` or the chunking settings only affects documents uploaded afterwards. Delete `./data/` to re-index from scratch.

## Tests

```bash
pytest                # fast suite, no network or API key needed (Claude and embeddings are faked)
pytest -m slow        # also checks retrieval with the real embedding model (downloads it once)
```

## Troubleshooting

| Symptom | Fix |
|---|---|
| `The Anthropic API key is missing or invalid.` | Set `ANTHROPIC_API_KEY` in `.env` and restart the server |
| `Your credit balance is too low...` | Add credits in the Anthropic Console under Plans & Billing, or use a key from an account with credits |
| `Model '...' was not found.` | Check `LLM_MODEL` is a valid Claude model ID |
| First upload is slow | The embedding model is still downloading or loading on first run |
| `Address already in use` | Run on another port: `uvicorn app.main:create_app --factory --port 8001` |
